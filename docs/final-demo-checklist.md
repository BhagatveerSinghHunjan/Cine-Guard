- [ ] Demo project loads (Load Demo Production → fictional input card)

- [ ] Analysis starts (202 + run id, no fake waiting)

- [ ] Parallel research executes (or honest not-run state, correctly labeled)
- [ ] Risks appear (ranked, deduplicated, with severity)
- [ ] Evidence appears (SCREENPLAY / RESEARCHED / INFERENCE / UNKNOWN)
- [ ] Dependency graph works (nodes clickable → detail drawers)
- [ ] Readiness score works (click score → real penalty breakdown)
- [ ] Mitigation selection works (checkboxes enable Build button)
- [ ] Revised plan works (actions, schedule impact, remaining blockers)
- [ ] Projected readiness changes dynamically (recomputed, never hardcoded)
- [ ] No secrets visible (health shows flags only; no keys in UI/network)
- [ ] No broken links (source links open in new tabs; nav tabs all render)
- [ ] No console errors (clean devtools console during full flow)
- [ ] Demo takes under 3 minutes (rehearse with docs/demo-script.md)

# CineGuard 3-minute demo script (~2:45)

## 0:00–0:20 — Problem + product introduction

"Every film production starts the same way: a screenplay full of hidden
dependencies — locations, permits, night shoots, stunts, weather — and a
producer who has to find them all before money burns. Miss one, and a
shoot day collapses. CineGuard is a production-risk agent: give it a
screenplay, and it tells you whether you can realistically shoot it."

## 0:20–0:45 — Load screenplay and start analysis

"This is Neon Harbor, a fictional demo screenplay — every name invented.
One click sends it through the real pipeline, and the backend opens a
persisted run. From here on, everything you see is polled live state —
stages, progress, events — never an animation."

## 0:45–1:15 — Autonomous workflow and Parallel research

"Watch the activity feed: parsed, dependencies identified, research
queries planned — one bounded Parallel Search per risky dependency.
Permits, brands, stunt rules. Each source comes back with title, domain,
URL and timestamp, and the analysis keeps going only when evidence
lands. No key, no sources, no pretending — the system says so."

## 1:15–1:50 — Readiness and major risk

"Readiness: computed, not guessed — severity weights times confidence,
minus mitigated items. The one-line explanation tells the story: blocked
by critical dependencies. Here's the biggest one — a rooftop helicopter
stunt with no confirmed permit."

## 1:50–2:15 — Evidence + dependency graph

"Every risk carries its provenance: screenplay facts quoted from the
script, researched facts with live sources, inferences labeled as
inferences, unknowns admitted outright. And the graph shows the blast
radius — one permit problem blocking these scenes and everything behind
them."

## 2:15–2:40 — Apply mitigations

"Now the fix-it moment. I select two mitigations — confirm the permit,
add a stunt safety day — and build the revised plan. The projected score
is recalculated by the backend scoring engine on the spot."

## 2:40–2:55 — Revised readiness and close

"Before: at risk. After: ready — with the remaining blockers listed
honestly, because that's next week's shooting plan. CineGuard helps
production teams solve dependencies before they become expensive
production problems."
